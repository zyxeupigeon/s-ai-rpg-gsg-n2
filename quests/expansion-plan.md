## ① 贸易城市（自建市镇 + 半自治特许状 + 选举结算）— 🔶 待详细设计

- **已定要点**：不自控老镇/西港，**自建市镇**（随 A3 集镇化升级）；发**半自治特许状**（保留重罪法庭+市税分成+任命权条款）；选举按**"收益换选票"结算规则**（我方保关键职位+多数派，个别席位旁落），配"年维护成本"与"影响力随收益衰减联动"两条规则。
- **依赖**：A3 集镇化基建（已完成启动）→ 市镇成型。
- **完成节点**：市镇成型 + 特许状颁发 + 首次选举结算（边境历 3 年秋）。
- **待详细设计**：城市位置 / 宪章条款 / 经济基础。

## ② 佣兵团（投奔吸收 → 拆分守备/进攻）— 🔶 待详细设计

- **已定要点**：某佣兵团投奔 → **吸收为正规军**（重点培养，验忠诚）→ 拆分为**守备正规军**（留驻防地/边堡，守备由我军管理）+ **恢复佣兵团**（进攻编制，安插监军骨干）；聚集地 = **我方授予的驻防地**（合同报酬+租约，保留续约/收回权）；"吸收后放出"需编制理由（野战轻装 vs 守备重装）。
- **依赖**：B1 卫队扩编（已完成）→ 吸收 → 培养 → 拆分。
- **完成节点**：秋-冬（拆分落地 + 进攻改革）。
- **待详细设计**：投奔事件 / 驻防地选址 / 编制与契约。

## ③ 教会脱钩（表面合作不变 + 四线脱钩）— ✅ 已定稿可执行

- **已定要点**：维持"合作者"人设；四条脱钩路径——
  - **什一税固定化**（切断随领地扩张自动增长）
  - **教区人事自荐**（建堂荐举权）
  - **司法管辖划界**（教会管圣职、世俗管民事）
  - **土地先占**（防教会地产随扩张扩张）
- 借**王权集权大势**（圣印之争下帮王廷削弱教会=政治红利）；**索尔薇格转教会内部窗口**；**不碰**教义/圣印权、圣泉修道院线 A 盟友。
- **依赖**：建堂（=集镇化/盐泉谷聚落）→ 荐举权落位。
- **完成节点**：冬（贡赋/人事/法庭/土地四线齐收）。
