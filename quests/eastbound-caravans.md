## 任务线标识

- **线名**：东境商队失踪（Merchant Caravans）· 线 C 局部介入
- **触发**：东边商队本月减三成（七灯/行会风声）→ 季月后主角+尤尔薇远征东境实地调查
- **关联调查线**：线 C（失踪的边境村庄——世界级调查线）

## 真相（GM 私有，线 C 局部）

- 商队减少的直接原因：**东境商路一段被「拜泉异端」与走私网把持**——商队要么被劫、要么被引导改道，失踪者多被异端网罗（腐化信仰/物色血约后人，忆者的网）。
- 远征发现：异端黑弥撒痕迹（泥沼边废弃谷仓/小圣所）、走私货物流向（经老狐狸式中间商→西港/卡尔登方向）、失踪商队留下的车辙与信物。
- **不揭全**：忆者/血约全貌留待线 C 主线推进（三证+更多证据）；本次为证据链+情报。

## 大纲 / 事件流程

1. 情报先行（丽芙：商队消息/东边风声）
2. 远征东境（主角+尤尔薇，240km，10 天）——泥沼边缘商道巡查
3. 发现：黑弥撒痕迹+走私路线+失踪商队信物（商队旗帜/货单残片）
4. 遭遇低阶蚀族骚扰（背景威胁，主角碾压无伤）
5. 回程——证据入档（线 C 认知推进），走私网与老狐狸/商行暗线交汇（线 B/C 交汇点）
