# Reasoning Audit · 推理审计

## Overview

写作/剧情推进前，用"反方视角"审计自己的方案——治逻辑硬伤、因果断裂、人设漂移（OOC）、证据不足。sequential-thinking 负责"正向推演"，本 skill 负责"反向质疑"。

## 核心铁律

1. **先推演，后审计**：先 sequential-thinking 拆因果链，再用本 skill 挑战它。不替代正向推演。
2. **红队视角**：故意站在"挑错"立场质疑方案——尤其自问"这里会不会有我不愿承认的漏洞"。
3. **NPC 动机锚点**：每个关键 NPC 过一遍"他最深层的、不可为小利违背的动机"——经营多年大阴谋者不会因一点小钱背弃大计划。
4. **证据链自洽**：调查线真相必须能对应此前埋的证据；证据不足不凭空揭晓。
5. **因果完整**：一个决策的连锁后果（经济→政治→军事→人情）要全列，不漏关联影响。

## 审计清单（叙事前过一遍）

### A. 逻辑硬伤
- [ ] 时间线是否自洽（用 date.js 核对日期）
- [ ] 地理/距离是否合理（移动速度、商路时长）
- [ ] 数字是否经脚本核算（不用 econ.js 手算 = 风险）
- [ ] 是否有"为了剧情需要"临时改已确定事实

### B. 人设一致性（OOC 检查）
- [ ] 每个关键 NPC 对照其【动机锚点】
- [ ] 反派是否"因小利背弃大阴谋"？（若有，是重大 OOC）
- [ ] 角色言行是否符合其身份/教育/文化/利益（对话风格规则）

### C. 因果链完整
- [ ] 本决策的直接后果全列了吗
- [ ] 连锁后果（经济/政治/军事/人情）漏了吗
- [ ] 是否遗漏"玩家同时不能分身"的维度（多线压力）

### D. 证据链
- [ ] 要揭晓的真相，证据是否已在此前埋下
- [ ] 证据不足时是否克制（不凭空揭晓）
- [ ] clues.md 台账能指认对应证据吗

### E. 世界一致性
- [ ] 技术/工艺是否用世界内描述（无现实原型名）
- [ ] 政治称谓是否本世界自洽（无现实王朝官制）
- [ ] 风格占比（如中式元素）是否越界

## 工作流

1. 叙事/大决策前，跑本审计清单（可对照 lessons-learned.md 的教训）。
2. 发现问题 → 修正方案（改设定/补证据/调动机）→ 再叙事。
3. 新增教训 → 记入 lessons-learned.md。

## Common Mistakes

| 错误 | 后果 | 纠正 |
|---|---|---|
| 只正向推演不反向质疑 | 逻辑硬伤漏网 | 先推演后审计 |
| 反派因小利背弃大阴谋 | OOC、世界失真 | 动机锚点对照 |
| 真相无证据链 | 临时反转、调查线崩 | 证据先埋、真相后揭 |
| 只算直接后果漏连锁 | 顾此失彼 | 全维度列连锁 |
